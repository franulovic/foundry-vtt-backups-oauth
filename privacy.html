Política de Privacidade

Última atualização: novembro de 2026

1. Finalidade

Foundry VTT Backups é uma integração OAuth de uso exclusivamente pessoal, destinada a armazenar cópias de segurança de um servidor Foundry Virtual Tabletop em uma conta privada do Google Drive.

2. Acesso aos dados

A integração utiliza a Google Drive API com o escopo drive.file, que permite acessar e gerenciar arquivos específicos autorizados para o aplicativo.

3. Utilização das informações

Os dados acessados são utilizados exclusivamente para criar, consultar, transferir, restaurar e excluir arquivos de backup administrados pelo proprietário da conta.

4. Compartilhamento de dados

Esta integração não comercializa dados pessoais nem os disponibiliza a terceiros. O Google Drive é utilizado como serviço de armazenamento.

5. Armazenamento e segurança

A integração é executada em um servidor privado administrado pelo proprietário. A autenticação utiliza OAuth 2.0 e as transferências para o Google Drive utilizam conexões HTTPS. O armazenamento de backups criptografados poderá ser configurado adicionalmente.

6. Retenção e exclusão

Os arquivos são mantidos conforme a política de retenção configurada pelo proprietário. O proprietário pode excluir os backups no Google Drive e revogar o acesso do aplicativo nas configurações de segurança da conta Google.

7. Contato

Para dúvidas sobre esta integração pessoal, utilize o e-mail de suporte informado na tela de consentimento OAuth.
